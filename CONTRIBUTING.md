# Sending a change

1. **Say which xlii you ran.** Give the version, and the install: `stock`,
   `alt` with its sign, or `dev`. A change made against an old release is
   fine; it just needs saying.
2. **Text parts go straight in:** a card (Markdown), a task (TOML), a seat's
   charter, a doc. Put them under the folder they belong in, the same as in
   xlii (`stock_plugins/`, `stock_tasks/`, …).
3. **Code** is welcome as a pull request against
   [xlii-computer/xlii](https://github.com/xlii-computer/xlii) or here as a
   patch. The maintainers port it into the next release and run the full
   gate on it. The pull request stays the record of who made it.
4. **No secrets.** A report or a change that holds a key is deleted.
